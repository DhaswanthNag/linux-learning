# 🔹 File & Directory Commands

Practical Linux command notes with screenshots. Replace the placeholder images in the `images/` folder with your own terminal screenshots.

## `ls`

List files and directories.

```bash
ls
```

![ls screenshot](images/ls.png)

## `ls -la`

List all files with detailed information.

```bash
ls -la
```

![ls-la screenshot](images/ls-la.png)

## `cd Documents`

Change directory.

```bash
cd Documents
```

![cd screenshot](images/cd.png)

## `cd ..`

Move to the parent directory.

```bash
cd ..
```

![cd-parent screenshot](images/cd-parent.png)

## `mkdir projects`

Create a directory.

```bash
mkdir projects
```

![mkdir screenshot](images/mkdir.png)

## `mkdir -p projects/linux/notes`

Create nested directories.

```bash
mkdir -p projects/linux/notes
```

![mkdir-p screenshot](images/mkdir-p.png)

## `touch notes.txt`

Create an empty file.

```bash
touch notes.txt
```

![touch screenshot](images/touch.png)

## `cp notes.txt backup.txt`

Copy a file.

```bash
cp notes.txt backup.txt
```

![cp screenshot](images/cp.png)

## `cp -r project project-backup`

Copy a directory recursively.

```bash
cp -r project project-backup
```

![cp-r screenshot](images/cp-r.png)

## `mv notes.txt linux-notes.txt`

Move or rename a file.

```bash
mv notes.txt linux-notes.txt
```

![mv screenshot](images/mv.png)

## `rm notes.txt`

Remove a file.

```bash
rm notes.txt
```

![rm screenshot](images/rm.png)

## `rm -r old-folder`

Remove a directory recursively.

```bash
rm -r old-folder
```

![rm-r screenshot](images/rm-r.png)

## `rmdir old-folder`

Remove an empty directory.

```bash
rmdir old-folder
```

![rmdir screenshot](images/rmdir.png)

## `file notes.txt`

Identify a file type.

```bash
file notes.txt
```

![file screenshot](images/file.png)

## `tree`

Display a directory tree (if installed).

```bash
tree
```

![tree screenshot](images/tree.png)
