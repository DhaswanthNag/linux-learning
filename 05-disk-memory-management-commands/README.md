# 🔹 Disk & Memory Management Commands

Practical Linux command notes with screenshots. Replace the placeholder images in the `images/` folder with your own terminal screenshots.

## `df -h`

Show filesystem disk usage.

```bash
df -h
```

![df screenshot](images/df.png)

## `du -sh *`

Show directory/file disk usage.

```bash
du -sh *
```

![du screenshot](images/du.png)

## `lsblk`

List block devices.

```bash
lsblk
```

![lsblk screenshot](images/lsblk.png)

## `free -h`

Display memory and swap usage.

```bash
free -h
```

![free screenshot](images/free.png)

## `uptime`

Show system uptime and load.

```bash
uptime
```

![uptime screenshot](images/uptime.png)

## `lscpu`

Display CPU information.

```bash
lscpu
```

![lscpu screenshot](images/lscpu.png)

## `lsmem`

Display memory ranges (if supported).

```bash
lsmem
```

![lsmem screenshot](images/lsmem.png)

## `mount`

Show or mount filesystems.

```bash
mount
```

![mount screenshot](images/mount.png)

## `findmnt`

Show mounted filesystems.

```bash
findmnt
```

![findmnt screenshot](images/findmnt.png)

```bash
sync
```
