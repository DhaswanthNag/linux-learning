# 🔹 Package & Compression Commands

Practical Linux command notes with screenshots. Replace the placeholder images in the `images/` folder with your own terminal screenshots.

## `sudo apt update`

Update package information on Debian/Ubuntu.

```bash
sudo apt update
```

![apt-update screenshot](images/apt-update.png)

## `sudo apt upgrade`

Upgrade installed packages.

```bash
sudo apt upgrade
```

![apt-upgrade screenshot](images/apt-upgrade.png)

## `sudo apt install git`

Install a package.

```bash
sudo apt install git
```

![apt-install screenshot](images/apt-install.png)

## `sudo apt remove git`

Remove a package.

```bash
sudo apt remove git
```

![apt-remove screenshot](images/apt-remove.png)

## `apt search git`

Search for packages.

```bash
apt search git
```

![apt-search screenshot](images/apt-search.png)

## `apt show git`

Show package information.

```bash
apt show git
```

![apt-show screenshot](images/apt-show.png)

## `dpkg -l`

Query/install Debian packages.

```bash
dpkg -l
```

![dpkg screenshot](images/dpkg.png)

## `tar -cvf project.tar project/`

Create a tar archive.

```bash
tar -cvf project.tar project/
```

![tar-create screenshot](images/tar-create.png)

## `tar -xvf project.tar`

Extract a tar archive.

```bash
tar -xvf project.tar
```

![tar-extract screenshot](images/tar-extract.png)

## `tar -czvf project.tar.gz project/`

Create a compressed tar.gz archive.

```bash
tar -czvf project.tar.gz project/
```

![tar-gz screenshot](images/tar-gz.png)

## `tar -xzvf project.tar.gz`

Extract a tar.gz archive.

```bash
tar -xzvf project.tar.gz
```

![tar-gz-extract screenshot](images/tar-gz-extract.png)

## `zip -r project.zip project/`

Create a ZIP archive.

```bash
zip -r project.zip project/
```

![zip screenshot](images/zip.png)

## `unzip project.zip`

Extract a ZIP archive.

```bash
unzip project.zip
```

![unzip screenshot](images/unzip.png)
